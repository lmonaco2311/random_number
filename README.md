# Guessing Game

## Description
This is a simple Python guessing game where the player tries to guess a randomly generated number.

## How It Works
- The program generates a random number between 1 and 100
- The user is prompted to guess the number
- The program provides feedback:
  - "Too low" if the guess is less than the number
  - "Too high" if the guess is greater than the number
- The game continues until the correct number is guessed

## Features
- Input validation (only accepts numbers)
- Continuous guessing until correct
- Helpful feedback after each guess
